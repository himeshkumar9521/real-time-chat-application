💬 Real-Time Chat Application

A full-stack real-time chat application that allows users to communicate through an interactive messaging interface.

* ✨ Features
* 💬 Real-time messaging
* 🟢 Online/offline user status
* 📱 Responsive chat interface
* ⚡ Fast and interactive user experience
* 🔒 Environment-based configuration
* 🔄 Real-time updates between users
* 🛠️ Tech Stack
* React
* JavaScript
* HTML
* CSS
* Node.js
* Express.js
* REST API
* Real-Time Communication
* Socket.IO
* Database: MongoDb
